# Badger File Viewer (web copy)

https://badgermetal.github.io/viewer/ — view DXF, MetaCAM .pdg / .3d, STEP / IGES / BREP, PDF and images in the browser.
Files are read on your device and never uploaded. Built from Badger Metal & Machine Fab's private file-viewer repo
(`tools/publish-web.cjs`); don't edit here. DWG is left out of this copy.

Third-party: three.js (MIT), occt-import-js and Open CASCADE (LGPL-2.1) — licenses in `lib/`.
